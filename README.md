# BellLab4TIQC 组织公开简介

此公开仓库用于维护组织在 GitHub 上的公开简介。

- `profile/README.md`：自动显示在 [组织主页](https://github.com/BellLab4TIQC) 的公开视图中。
- [组织网站](https://belllab4tiqc.github.io/)：由 [`belllab4tiqc.github.io`](https://github.com/BellLab4TIQC/belllab4tiqc.github.io) 仓库维护。

修改简介时，编辑 `profile/README.md` 并提交到默认分支即可。此仓库的内容对所有人可见；成员内部的仓库说明应保存在相应的私有仓库中。
